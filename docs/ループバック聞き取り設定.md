# Discord通話の聞き取り（ループバック取り込み）

## 仕組みと制約

Discord通話の受信は、ホストPCのDiscordデスクトップアプリが再生した音声を
WASAPIループバックで取り込みます。BotはVCへTTSを送信できますが、DAVE（E2EE）通話の
受信・復号は `discord-ext-voice-recv` では安定して扱えないため、このアプリでは使いません。

そのため、**ホスト本人のDiscordアプリが対象VCに参加し、通話音声を再生していることが必要**です。
ホストがVCにいない場合、PC側に通話音声が出ないため、他の参加者の音声をポポへ届けることはできません。

## 推奨構成

- Discord出力: Elgato Sound Capture
- ポポの「Discord音声取得デバイス」: Elgato Sound Capture
- モニター再生先: Razer BlackShark V2 Pro
- AI音声再生先: Razer BlackShark V2 Pro
- 本人マイク: 物理マイク

Discordアプリの出力先もElgato Sound Captureに設定してください。
AI音声をRazerへ分離するこの構成では、設定の
「AI音声もDiscord音声取得デバイスへ流す場合のみ、AI発話中の取得を止める」は **OFF** にします。
これにより、AI発話中でも相手のDiscord音声をループバックから取り込み、割り込みとして扱えます。

## 注意

- ループバックは通話音声が1本のミックスになるため、話者ごとのDiscord表示名は取得できません。
- VCへ入り直した直後の3秒間は無音診断を行います。無音警告が出た場合は、Discordアプリの出力先と
  「Discord音声取得デバイス」が同じElgato endpointか確認してください。
