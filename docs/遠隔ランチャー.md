# 遠隔ランチャー (外出先スマホから 起動・参加・退出・終了)

外出先のスマートフォンから、Neuro Voice AI 本体を **起動 → Discord VCへ参加 →
退出 → 終了** まで安全に操作するための仕組みです。PCは常時起動しておきますが、
AI本体(音声認識・合成・LLM・Discord受信など重い処理)は常時は動かさず、必要な
ときだけスマホから起動します。

外部インターネットには一切公開せず、**Tailscale のプライベートネットワーク内から
のみ**アクセスできる構成です。

> スマホ用の画面(PWA)まで実装済みです。Windowsタスクスケジューラでの常駐化
> (PC再起動後の自動起動)と実機での通し確認は次段階で行います。

---

## 全体アーキテクチャ

```
スマートフォン
   │  Tailscale (プライベートネットワーク)
   ▼
軽量ランチャー (remote_launcher.py) ← 常時起動しておくのはこれだけ
   │  localhost の内部制御 (トークン認証)
   ▼
AI本体 (python run.py --discord) ← スマホ操作で起動/終了する
   ▼
Discord
```

- **常駐するもの**: 軽量ランチャーのみ。スマホ画面の提供・認証・AI本体の起動/監視/
  終了・状態表示・監査ログだけを担当し、音声やLLMは一切読み込みません。
- **常駐しないもの**: AI本体、音声認識、音声合成、Discord受信、LLM、会話処理。

## 常駐方式について

AI本体(GUIモード)はデスクトップ画面を必要とするため、ランチャーは
**Windowsタスクスケジューラの「ログオン時」トリガー**で常駐させる方針です
(Windows ServiceはSession 0でGUI起動に問題が出るため採用しません)。
※タスクスケジューラ登録手順は次段階で追記します。現段階では手動起動で確認できます。

なお、遠隔からはGUIではなく **`run.py --discord`(ヘッドレスBot専用モード)** を
起動します。外出先ではローカルの画面・マイクは不要で、DAVE直接受信で通話を聞くこの
モードが最適だからです。

## セットアップ

### 1. Tailscale を導入する

1. PCに Tailscale をインストール: https://tailscale.com/download/windows
   インストール後、自分のアカウントでログイン。
2. スマートフォンにも Tailscale アプリを入れ、**同じアカウント**でログイン。
3. PCのTailscale IPを確認: コマンドプロンプトで `tailscale ip -4`
   (`100.x.x.x` の形。ランチャーは既定でこれを自動検出します)。

### 2. 管理トークンを生成する

Discordのトークンとは**別の**管理用トークンを作ります。コマンドプロンプトで:

```
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

出力された文字列を、`.env` の `REMOTE_LAUNCHER_ADMIN_TOKEN=` に貼り付けます。

### 3. .env を設定する

`.env.example` の「遠隔ランチャー」節を参考に、`.env` へ以下を設定します(最低限):

```
REMOTE_LAUNCHER_ENABLED=true
REMOTE_LAUNCHER_ADMIN_TOKEN=<上で生成したトークン>
# よく使うVCがあれば (任意):
DEFAULT_DISCORD_GUILD_ID=<サーバーID>
DEFAULT_DISCORD_CHANNEL_ID=<ボイスチャンネルID>
```

Discord Bot トークン(`DISCORD_BOT_TOKEN`)も従来どおり必要です。

### 4. ランチャーを起動する

`RemoteLauncher.vbs` をダブルクリックします。**コンソールは出ず、タスクトレイ
(通知領域)にアイコンが常駐**します。
従来の`RemoteLauncher.bat`もこの非表示入口へ委譲する互換用として残していますが、
手動起動は`.vbs`を使ってください。`pythonw.exe`がない環境で`python.exe`へフォールバックしても、
非表示のまま実行します。

- トレイアイコンを**クリック**(または右クリック→「状態とログを表示」)すると、
  ランチャー/AI本体/Discordの現在状態と、**ポッポとの会話ログ**(run.py --discord の
  やり取り)がリアルタイムで見られるウィンドウが開きます。ランチャーの動作ログと
  会話ログを時刻順にマージし、`[ポッポ]`/`[launcher]` のタグ付きで表示します
  (約1.5秒ごとに自動更新。×で閉じてもトレイに残る)。会話に関係ない大量の
  内部ログ(認識処理・検索等)は除外して読みやすくしています。
- 右クリック→「終了」でランチャーを停止できます。
- トレイに出ない/エラーを見たいときは `RemoteLauncher_Console.bat`(コンソール表示)。
- トレイ機能には `pip install pystray pillow` が必要です。未導入でもサーバー自体は
  ヘッドレスで動きます。

コマンドから直接動かす場合:

```
python remote_launcher.py            # トレイ常駐
python remote_launcher.py --console  # コンソール表示 (トレイなし)
```

起動すると `遠隔ランチャーを起動します: http://100.x.x.x:8765 (Tailscale内のみ)` と
ログ(トレイのウィンドウ / logs\remote_launcher.log)に出れば成功です。Tailscale IPを検出できない場合、安全のため**起動しません**
(LANやインターネットへ勝手に公開しないため)。開発中にlocalhostで試したいときだけ
`REMOTE_LAUNCHER_ALLOW_LOCALHOST=true` を設定してください。

## スマホからの使い方

スマホのブラウザで `http://100.x.x.x:8765`(あなたのPCのTailscale IP)を開くだけです。
専用の管理画面が表示されます。

1. **ログイン**: 管理トークンを入力してログイン(以後はCookieで自動認証)。
2. **ボイスチャンネルを選ぶ**: ドロップダウンから選択(既定/自動でもOK)。
3. **「起動して参加」をタップ**: AI本体の起動 → Ready確認 → VC参加まで自動で進み、
   状態カードがリアルタイムに更新されます。
4. 使い終わったら **「退出して終了」**(確認ダイアログあり)。

画面には ランチャー稼働状態 / AI本体の状態 / Discord接続 / サーバー名 / VC名 /
実行中の処理 / 最後の操作 / 最後のエラー / 最終更新時刻 が表示されます。処理中は
ボタンが自動で無効化され、二重タップを防ぎます。折りたたみの「詳細操作」から、
本体のみ起動/終了・VCのみ参加/退出も個別に行えます。

### ホーム画面に追加 (PWA)

- **iPhone (Safari)**: 共有ボタン → 「ホーム画面に追加」。
- **Android (Chrome)**: メニュー(⋮) → 「アプリをインストール」または「ホーム画面に追加」。

追加すると全画面アプリのように起動できます。オフライン時は画面の枠だけ表示され、
「ランチャーに接続できません」と明示します(古い状態を現在として見せません)。

### API を直接使う場合

ブラウザ画面を使わず、ショートカットアプリ等から直接叩くこともできます。

ベースURL: `http://100.x.x.x:8765`

| 操作 | メソッド / パス | 本文 |
|---|---|---|
| ヘルスチェック(認証不要) | `GET /api/health` | - |
| ログイン | `POST /api/login` | `{"token":"<管理トークン>"}` |
| 状態取得 | `GET /api/status` | - |
| VC一覧 | `GET /api/discord/channels` | - |
| 起動して参加(ワンタッチ) | `POST /api/actions/start-and-join` | `{"guild_id":"...","channel_id":"..."}` |
| 退出して終了(ワンタッチ) | `POST /api/actions/leave-and-stop` | - |
| 本体のみ起動 | `POST /api/app/start` | - |
| 本体のみ終了 | `POST /api/app/stop` | - |
| VCのみ参加 | `POST /api/discord/join` | `{"channel_id":"..."}` |
| VCのみ退出 | `POST /api/discord/leave` | - |
| 操作の進捗確認 | `GET /api/operations/{operation_id}` | - |

補足:
- ログイン後はHttpOnly Cookie(`nvsession`)で認証されます。
- 状態を変える`POST`には、CSRF対策としてヘッダ `X-Requested-With: NeuroLauncher` が
  必要です(PWA画面が自動付与します)。
- 起動・終了・参加などの時間がかかる操作は、すぐに `operation_id` を返します。
  `GET /api/operations/{id}` を数秒おきに確認し、`SUCCEEDED` / `FAILED` を待ちます。

### 動作の流れ (ワンタッチ「起動して参加」)

1. AI本体が停止中なら起動 → 本体からの **Ready通知** を待つ(固定秒数のsleepではなく、
   Discordログイン完了まで確認)。
2. 指定VCへ参加。既に同じVCに居れば、冪等操作として成功扱い。
3. `GET /api/status` で `discord_state: CONNECTED` を確認。

「退出して終了」は、退出 → 本体へ正常終了要求 →(必要時のみ強制終了)→ `STOPPED`。

## 安全設計 (何をしないか)

- 待ち受けは Tailscale IP のみ。`0.0.0.0` へは絶対にバインドしません。
- 認証必須。管理トークンはソースに直書きせず `.env` から読み、ログにも出しません。
- 任意コマンド実行・任意ファイル読み書き・シェル実行のAPIは**ありません**。
  起動できるのは設定済みの `run.py --discord` **だけ**で、実行ファイルや引数を
  外部から変更することはできません。
- AI本体のlocalhost制御ポート(既定8766)は外部に公開しません。ランチャーとの間は
  起動ごとに生成するランダムな共有シークレット(環境変数経由、コマンドライン非経由)で
  認証します。
- 連打しても二重起動・二重参加・二重終了は起きません(状態機械+排他ロック)。
- AI本体がクラッシュした場合、ランチャーは状態を `ERROR` にし、Discordを
  `CONNECTED` のまま表示しません。自動再起動はしません。

## トラブルシューティング

- **スマホからつながらない**: 両方の端末が同じTailscaleアカウントでログインし、
  オンライン表示になっているか確認。PCで `tailscale ip -4` が値を返すか確認。
- **ランチャーが起動しない**: `REMOTE_LAUNCHER_ENABLED=true` と 32文字以上の
  `REMOTE_LAUNCHER_ADMIN_TOKEN` が設定されているか、Tailscaleが起動しているか確認。
- **AI本体が起動しない/タイムアウト**: `logs/remote_launcher.log`(監査ログ)と
  `logs/neuro_voice.log` を確認。`DISCORD_BOT_TOKEN` の設定漏れが多いです。
- **VCに参加できない**: Botがそのサーバーに招待され、対象VCへの接続権限を持っているか
  確認。`GET /api/discord/channels` に出ないチャンネルには参加できません。

## 無効化・ロールバック

`.env` の `REMOTE_LAUNCHER_ENABLED=false` にすればランチャーは起動しません。
遠隔ランチャー関連のコードは `neuro_voice/remote/` と `remote_launcher.py` に
まとまっており、既存の会話・音声・Discord機能には手を加えていません
(AI本体側の追加は、環境変数が無ければ何もしない制御サーバーのみ)。
