# 爆弾解除の表を取り込む

キーパッド・心理戦・迷路の3つは、**解法はコードに入っているが、表が空**である。
このファイルの手順で埋めると、ポッポが指示を出せるようになる。

## なぜ空で出荷したか

この3つは解法そのものは単純なのに、表が大きい。

| モジュール | 表の量 |
|---|---|
| キーパッド | 6列 × 7記号 |
| 心理戦 | 画面の語28件 + 語ごとの順序付きリスト28本 |
| 迷路 | 9面 × 6×6の通路 |

これを記憶から書き起こすと、**一箇所間違えても誰も気づかない**。
気づくのは爆発した時である。だから公式マニュアルを見ながら写す作業として
分離した。写すのは30分ほどで済む。

**AIに「たぶんこうだったはず」で埋めさせないこと。** これは他の作業と違い、
間違いが静かに残る。

## 出典

- 公式マニュアル（無料・日本語版）: <https://www.bombmanual.com/ja/web/index.html>
- 版 `1-ja` / 検証コード `122`（`profile.json` の `manual` と一致させること）

## 置き場所

```
game_profiles/keep_talking_and_nobody_explodes/manual/tables/
  keypad.json
  whos_on_first.json
  maze.json
```

書き換えたら **ポッポを再起動**する（セッション開始時に読む）。
書式が壊れていても会話は止まらない。その表だけ「未取り込み」の扱いになる。

## keypad.json

マニュアルの『キーパッド』のページにある6本の列を、上から順に書く。

```json
{
  "columns": [
    ["丸に線", "稲妻", "逆さのC", "しっぽ付きの6", "変なA", "三本線", "水滴"],
    ["星", "稲妻", "しっぽ付きの6", "はてな", "三本線", "変なA", "うずまき"]
  ]
}
```

記号に決まった読み方は無いので、**呼び名は自分で決めてよい**。
ポッポへ言う時も同じ呼び名を使う。

```
記号は 丸に線、稲妻、三本線、水滴
→ 「丸に線、稲妻、三本線 の順に押して」
```

呼び名がぶれると当たらないので、自分が口に出しやすい名前にしておくとよい。

## whos_on_first.json

2つの表を写す。位置は左上を1として右へ2、中段が3と4、下段が5と6。

```json
{
  "display_to_position": {
    "YES": 3,
    "FIRST": 2,
    "": 5
  },
  "label_to_order": {
    "READY": ["YES", "OKAY", "WHAT", "MIDDLE"],
    "NOTHING": ["UHHH", "RIGHT", "OKAY", "MIDDLE"]
  }
}
```

- 画面が空欄の場合は `""` というキーで書く
- `THEY'RE` と `THEYRE` は同じものとして扱われるので、どちらで書いてもよい
- `label_to_order` の**順番が答えそのもの**。並べ替えないこと

会話は2段構えになる。

```
画面は YES
→ 「左上から数えて3番目のボタンを見て。そこに書いてある語と、6つのボタンの語を教えて」
3番目は READY、ボタンは MIDDLE, WHAT, READY, OKAY, NOTHING, UHHH
→ 「OKAY を押して」
```

## maze.json

9面を写す。座標はすべて `[列, 行]` の1始まりで、左上が `[1,1]`、右下が `[6,6]`。

```json
{
  "mazes": [
    {
      "name": "丸が [1,2] と [6,5] の面",
      "circles": [[1, 2], [6, 5]],
      "passages": [[[1, 1], [2, 1]], [[2, 1], [2, 2]]]
    }
  ]
}
```

- `circles` は面を見分ける丸2つ
- `passages` は**壁ではなく「通れる隣り合わせ」**を書く。
  片方向だけ書けばよく、逆向きはコードが補う
- 最短経路は幅優先探索で出すので、道順を書く必要はない

会話はこうなる。

```
丸は左から1番目の上から2番目と、左から6番目の上から5番目
白い四角は左から3、上から1
赤い三角は左から5、上から4
→ 「右、下、下、右 の順に動かして」
```

## 埋め終わったら

`tests/test_ktane_tables.py` が書式を検証する。

```
python -m pytest tests/test_ktane_tables.py -q
```

`test_the_shipped_files_are_valid_but_empty` は空を前提にしているので、
埋めた後は落ちる。**それは正常**なので、埋めたらこのテストを
「取り込み済み」を確かめる形へ書き換えること。

そのまま使える。
