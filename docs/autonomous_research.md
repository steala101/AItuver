# 自律研究・学習履歴

自律研究は、会話中の即時 `DeepSearch` とは別の低優先度ワーカーです。沈黙を埋めるための検索や、HeartbeatごとのLLMによる話題生成はしません。

## 起点と優先順位

- 明示的な「あとで調べておいて」「検索しておいて」は `USER_REQUEST` として記録されます。
- 実行は通常のSTT・応答・TTSより低優先度です。応答中、発話中、Discordで人が話している間は待機します。
- Heartbeatは期限確認と既存キューへの追加だけを行います。具体的な `ResearchQuestion` が無ければ何もしません。

## 安全境界

- すべての研究に reason code が必須です。ランダム、退屈、沈黙埋めを理由にすることはできません。
- メール、電話、住所、Discord ID、URL、トークン/APIキー、個人関係を含む入力は検索せず、内容を保存しないブロック履歴だけを残します。
- 医療・法律・金融・政治・セキュリティ・個人に関する話題は自動実行せず、承認待ちにします。
- 外部ページは未信頼データです。ページ中の命令、URL、設定変更要求、ツール実行要求には従いません。注入らしい文面を含む証拠は `REJECTED` にします。

## 知識化

各ペルソナの `data/research_<persona>.db` に、質問・実行・Evidence・知識候補を分離して保存します。検索結果1件だけは `PROVISIONAL` であり、確定知識にはなりません。異なる2ドメイン、または公式一次資料がある場合だけ `ACTIVE` として採用します。知識候補には30日の確認期限があります。

研究完了は会話へ割り込みません。通常は `REPORT_WHEN_RELEVANT` で保存し、明示的な依頼だけ `REPORT_NOW` の候補になります。

## 設定と履歴

設定 → 機能で「自律研究」とモードを切り替えられます。既定は `LOW_RISK_AUTO` です。こころステータスの「自律研究」カードには、今日の実行数、待機件数、学習済み件数と、サニタイズ済みの直近履歴だけを表示します。

`autonomous_research` の既定上限は1時間2件、1日5件、同時1件、重複防止72時間です。
