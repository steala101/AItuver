# Game Profiles

ゲーム固有の役割・知識・映像方針を、ゲームごとのフォルダで管理します。
設定画面の「ゲームプロファイル」一覧は各フォルダの `profile.json` から生成されます。

| フォルダ | ゲーム | ポッポの役割 | 映像 |
|---|---|---|---|
| `minecraft/` | Minecraft | 画面を見ながら助言する相棒 | 使用する |
| `keep_talking_and_nobody_explodes/` | Keep Talking and Nobody Explodes | マニュアルを読むエキスパート | 見ない |

## 会話で切り替える

`config.yaml` を手で編集しなくても、話しかけるだけで切り替わります。

```
爆弾解除モードにして        → KTANEへ切り替え
爆弾解除を始めよう          → KTANEへ切り替えて、そのままセッション開始
マイクラに戻して            → Minecraftへ戻す（爆弾解除セッションは終了）
今どのゲームモード？        → 現在のプロファイルとセッションの進行状況
```

- 切り替わるのは、**「切り替えて」と読める言い方**と**プロファイルの別名**が
  同じ発話に両方そろった時だけです。「マイクラの話なんだけどさ」や
  「静かにして」では何も起きません
- 選んだ結果は `video.game_profile` として `config.yaml` へ書き戻されるので、
  次回の起動でも同じモードで立ち上がります
- 映像を使わないプロファイルへ移ると、画面キャプチャもその場で止まります
  （アプリの再起動は不要）
- 登録のないゲーム名を言われた場合、勝手に切り替えず、使えるものを答えます

別名は `profile.json` の `aliases` で増やせます。

## 新しいゲームを追加する

英小文字・数字・`_` だけのフォルダを作り、その直下へ `profile.json` を
置いてください。実行コードはJSONから読み込まず、
ゲーム固有の処理は `neuro_voice/games/` 側でプロファイルIDに明示的に登録します。
